# Changelog

## [0.1.0] - 2026-11-08

First release.

### Added

- Commands: `architecture`, `flow`, `erd`, `sequence` and `diagram`.
- `drawio-diagram` skill, with references for the draw.io format, styles, layout and language-agnostic repo analysis.
- `scripts/validate_drawio.py`: structural checks on `.drawio` files, using only the Python standard library.
- `scripts/export.sh`: optional export to editable `.drawio.svg` and `.drawio.png` files through draw.io desktop.
- Marketplace listing for installing from GitHub.
